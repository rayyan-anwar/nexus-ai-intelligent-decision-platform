# Code of conduct

We want this project to be a respectful, harassment-free space for everyone, regardless of background, identity, experience level or opinion.

## Expected behaviour

* Be kind and assume good intent; disagree with ideas, not people.
* Give and accept constructive feedback gracefully.
* Respect others' time: keep discussions on topic and issues reproducible.

## Unacceptable behaviour

* Harassment, discrimination, insults, threats or personal attacks.
* Publishing someone's private information.
* Sexualised language or imagery, or unwelcome attention.
* Sustained disruption of discussions.

## Enforcement

Maintainers may edit or remove comments, close discussions, or restrict participation to protect the community. To report a problem, contact the maintainer privately through the contact method listed on the repository owner's GitHub profile, or use GitHub's "Report content" feature. Reports are handled confidentially where possible.

This code of conduct applies in all project spaces. It is a short, original statement inspired by common open-source community norms.
